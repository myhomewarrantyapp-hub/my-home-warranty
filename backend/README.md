# Backend API starter

This folder is the initial deployable Express API scaffold. It exposes a health endpoint and public site-status endpoint only. It is **not yet the complete application API**.

## Local setup
1. Copy .env.example to .env and fill values privately.
2. Run npm install.
3. Run npm run build.
4. Run npm start.

Database schema, migrations, authentication, owner-scoped modules, and production deployment must be added and tested before production use. Never commit .env or credentials.
